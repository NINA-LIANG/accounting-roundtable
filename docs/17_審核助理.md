# 會計圓桌｜審核助理（v0.1，2026-11-13）

目的：需求者每次審核只看三行重點、用點選回答，判斷仍由需求者本人做；每一次選擇都留下論文可用的決策紀錄。

## 每次要審的東西（文章、PR、勘誤）怎麼送
1. **三行重點**（AI 寫）
   - 改了什麼：一句話
   - 引用哪些法條：條號清單
   - 風險最高的一句：直接引出文章原句，並說明為什麼有風險
2. **AI 建議**：AI 推薦哪個選項、為什麼（一句）
3. **點選卡**：2–4 個選項，例如「核准」「退回改寫（附理由）」「下架」「維持原文」。需求者點選；想補充就在討論串打一句話。

## 紀錄
- 檔案：law-site/logs/審核紀錄.csv（只追加，不改舊列）。
- 欄位：紀錄編號、送審時間、項目、三行重點、風險句、AI 建議、需求者選擇、選擇時間、需求者自己的話、後續動作。
- 「需求者選擇」只在需求者點選或親自打字之後才寫入；AI 不代填、不代寫想法。
- 需求者沒有選擇前，項目一律停在待審。

## 原則
- AI 只提供建議，核准由需求者本人做；網站上線仍以需求者合併 Pull Request 為準。
- 建議可以被否決；否決也是有價值的論文資料（衡量 AI 建議和人工判斷的一致率）。

## v0.2 追加（2026-11-13，配合論文研究設計 v3 第十節）
