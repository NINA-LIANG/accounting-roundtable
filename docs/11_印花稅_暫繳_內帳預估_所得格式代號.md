## 一、印花稅：廣告業簽合約最容易漏

### 1.1 規則（官方問答，知識庫未涵蓋）

| 憑證 | 稅額 | 誰貼 |
|---|---|---|
| 承攬契據（一方為他方完成一定工作） | 每件按金額千分之一 | 立約雙方各就自己持有的那一份負責 |
| 買賣動產契據 | 每件 12 元 | 同上 |
| 銀錢收據 | 依印花稅法規定（實務上營業人收據多已有免貼規定，需另查） | 立據人 |

**廣告業常見情況**
- 承攬廣告樣品分送、廣告傳單分送、展覽會佈置、廣告促銷活動等，與委託人訂的承攬合約，要按合約金額千分之一貼印花。
- 委託綜合性廣告代理商的合約，若代理商要完成市場分析、企劃、製作與媒體刊播等「一定工作」，財政部函釋認為屬承攬契據，媒體刊播費也要計入金額。
- 合約沒有寫總價、完工才能結算的，先以預計金額貼用，結算後再補（各地方稅務局宣導手冊）。

### 1.2 實務做法

1. 合約管理表加一欄「印花稅：類別、金額、貼用日期」，簽約當月就處理。
2. 稅額 = 合約未稅或含稅金額，請以稅務局見解為準，各地方稅務局手冊有實例。
3. 雙方各持一份正本，各自貼；影本不用貼。
4. 印花稅費用列「稅捐」。
5. 電子簽約是否免貼、彙總繳納怎麼申請，網路說法多但這次沒有找到原始函釋，引用前請查財政部或地方稅務局原文。

## 二、每年 9 月的營所稅暫繳

### 2.1 規則（知識庫）

| 問題 | 規則 | 法條 |
|---|---|---|
| 什麼時候 | 每年 9 月 1 日到 9 月 30 日 | 所得稅法第 67 條第 1 項 |
| 繳多少（一般） | 上年度結算申報應納稅額的二分之一 | 所得稅法第 67 條第 1 項 |
| 要不要另外申報 | 沒有用投資抵減、行政救濟留抵、扣繳稅額去抵的，自己繳完款就可以免申報 | 所得稅法第 67 條第 2 項 |
| 可以用今年上半年試算嗎 | 公司組織、帳冊完備、使用藍色申報書或會計師簽證、如期申報者可以 | 所得稅法第 67 條第 3 項 |
| 晚繳 | 10 月 31 日前補繳，從 10 月 1 日起按日加計利息；過 10 月 31 日，國稅局直接核定並加計一個月利息 | 所得稅法第 68 條 |
| 誰不用暫繳 | 獨資、合夥、小規模營利事業、依法免徵營所稅者等 | 所得稅法第 69 條 |

### 2.2 實務做法

1. 8 月底前，把去年營所稅申報書的「應納稅額」找出來，除以 2。
2. 今年上半年業績明顯變差的公司，評估用上半年試算是否比較省（需符合第 67 條第 3 項資格，通常由會計師處理）。
3. 分錄：繳款時 借 預付所得稅／貸 銀行存款；隔年 5 月結算時，暫繳稅款抵減應納稅額。
4. 去年沒有應納稅額（例如虧損），一般不用暫繳。暫繳稅額很小的，網路文章提到 2,000 元以下有免繳規定，但這次沒有在知識庫找到條文，需另查。

## 三、內帳：每月預估收入費用，並和去年同期比較

這部分是管理會計，沒有法條規定格式，但它是會計轉 FP&A 最重要的能力。

### 3.1 工廠內帳常見的三張表

| 表 | 做什麼 | 資料從哪來 |
|---|---|---|
| 預估損益（Forecast） | 預估本月、下月到年底的收入與費用 | 業務訂單、出貨計畫、產能、物料清單（BOM）、人力計畫 |
| 實際對預估（Actual vs Forecast） | 月結後比較實際和預估，說明差異 | 月結報表 |
| 和去年同期比較（YoY） | 本月與去年同月、今年累計與去年同期累計比較 | 本年與去年月報 |

### 3.2 建議的月報欄位

| 項目 | 本月實際 | 本月預估 | 差異 | 差異 % | 去年同月 | 年增率 % | 今年累計 | 去年同期累計 |
|---|---|---|---|---|---|---|---|---|
| 營業收入 | | | | | | | | |
| 營業成本 | | | | | | | | |
| 毛利 | | | | | | | | |
| 營業費用 | | | | | | | | |
| 營業利益 | | | | | | | | |

### 3.3 差異說明怎麼寫

不要只寫「收入比去年高」，要拆成可以驗證的原因：

1. **量**：出貨數量變多或變少。
2. **價**：售價或原物料單價變動。
3. **組合**：高毛利與低毛利產品比重改變。
4. **一次性項目**：設備維修、專案獎金、退貨。
5. **時間差**：去年 12 月出貨、今年 1 月才認列等。

例句（虛構）：「本月收入較去年同月增加 12%，主要是 A 產品出貨量增加 15%（量），但平均售價下降 3%（價）；製造費用增加 8%，主要是 9 月一次性設備維修 30 萬元。」

### 3.4 實務做法

1. 預估每月滾動更新（滾動預測），不要一年只做一次預算。
2. 費用預估要和月結估列一致：已發生、發票未到的費用，月底就估列（查核準則第 64 條，見 07 文件第 6 名）。
3. 差異超過門檻（例如 5% 或金額 10 萬元）才需要寫原因，避免報告太長。
4. 去年資料若有重分類，要先調成同口徑再比較。

## 四、所得格式代號：50、9A、9B、92、53、51 怎麼選

### 4.1 對照表（居住者；扣繳率已對照各類所得扣繳率標準第 2、13 條）

| 代號 | 所得類別 | 常見例子 | 所得稅扣繳 | 二代健保補充保費 |
|---|---|---|---|---|
| 50 | 薪資（含兼職） | 員工薪資、兼職人員、內部講師授課 | 依薪資扣繳辦法；非固定薪資常見 5% | 兼職單次達最低工資要扣 |
| 9A | 執行業務所得 | 律師、會計師、建築師、設計師、表演人、工匠 | 10%；扣繳稅額 2,000 元以下免扣（實務上給付 20,010 元以上才扣） | 單次達 2 萬元要扣 |
| 9B | 稿費、版稅、講演鐘點費 | 演講、寫稿、作曲、編劇、漫畫 | 同 9A | 單次達 2 萬元要扣 |
| 92 | 其他所得 | 不屬於其他各類的所得，例如部分競賽獎品、研討會出席獎勵等 | 一般不扣繳，開免扣繳憑單 | 不扣 |
| 53 | 權利金 | 專利、商標、著作權、特許權授權費 | 10%；扣繳稅額 2,000 元以下免扣 | 不在六類之內 |
| 51 | 租金 | 個人房東 | 10%；扣繳稅額 2,000 元以下免扣 | 單次達 2 萬元要扣 |

非居住者的扣繳率不同（例如 9A、53 一般為 20%），並要在給付後 10 日內繳款申報（見 08 文件）。

### 4.2 最常見的判斷問題

1. **講師費是 50 還是 9B？** 依國稅局見解，屬「授課」（有固定課程、按時授課）多為薪資 50；屬「講演」（一次性演講）多為 9B。內部員工兼任講師給的鐘點費通常是 50。
2. **外包設計是 50 還是 9A？** 有僱傭關係、受公司指揮監督的是 50；以自己的專業獨立完成、自負盈虧的是 9A。
3. **9B 的好處**：個人稿費、版稅、講演鐘點費等，全年合計 18 萬元以內免稅（所得稅法第 4 條第 1 項第 23 款），但公司仍要依規定扣繳與申報。
4. **勞務報酬單**：同一張勞報單要選對代號，扣繳率與二代健保起扣點都不同；選錯會造成短扣或多扣。

### 4.3 法條對照（知識庫）

- 所得稅法第 14 條第 1 項：第二類執行業務所得、第五類租賃所得及權利金所得、第十類其他所得的定義。
- 所得稅法第 4 條第 1 項第 23 款：個人稿費、版稅、樂譜、作曲、編劇、漫畫及講演鐘點費，全年合計 18 萬元以內免稅。
- 所得稅法第 88、92、114 條：扣繳義務、期限與罰則。
- 營利事業所得稅查核準則第 85 條：勞務費應於給付時扣繳，原始憑證為收據或匯款證明。
- 各類所得扣繳率標準第 2 條（擴充後補對）：居住者租金、權利金、執行業務者報酬均按給付額扣 10%；薪資可選依扣繳辦法或全月給付總額 5%。
- 各類所得扣繳率標準第 13 條（擴充後補對）：居住者每次應扣繳稅額不超過 2,000 元者免予扣繳。
- 各類所得扣繳率標準第 3 條（擴充後補對）：非居住者執行業務報酬、租金、權利金均扣 20%；稿費、版稅、講演鐘點費每次不超過 5,000 元得免扣。
- 全民健康保險法第 31 條與補充保險費辦法第 4 條（擴充後補對）：執行業務收入、租金等單次達 2 萬元扣補充保費；權利金不在六類之內。
- 知識庫未涵蓋：薪資所得扣繳辦法。

## 五、給會計圓桌的用法

1. 「廣告業會計」可以當一個系列：印花稅、預收款與收入調節（見 09 文件）、外包 9A 與 50 的判斷。
2. 題庫候選：
   - 9 月暫繳的一般計算方式？（上年度應納稅額二分之一；所得稅法第 67 條）
   - 10 月 31 日前補繳暫繳稅額，利息從哪天起算？（10 月 1 日；所得稅法第 68 條）
   - 個人稿費全年多少以內免稅？（18 萬元；所得稅法第 4 條第 1 項第 23 款）
   - 獨資商號要不要暫繳？（不用；所得稅法第 69 條）
3. 知識庫擴充：印花稅法、各類所得扣繳率標準、薪資所得扣繳辦法。
